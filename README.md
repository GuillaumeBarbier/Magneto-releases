# Magneto — versions publiées

Gestion des fenêtres pour macOS 13 et plus (Apple Silicon et Intel). Ce dépôt ne contient que les builds ; le code source est privé.

## Installer

Dans le Terminal :

```bash
curl -fsSL https://github.com/GuillaumeBarbier/Magneto-releases/releases/latest/download/install.sh | bash
```

Puis, au premier lancement, autoriser Magneto dans *Réglages Système › Confidentialité et sécurité › Accessibilité*.

Ensuite Magneto se met à jour seul (vérification au lancement puis toutes les 6 h). Menu de la barre des menus : « Rechercher les mises à jour… ».
